# 메뉴 환율 제공·유효 기간 정책

## 서비스 선정

메뉴 참고 환산 가격의 환율 제공 서비스는 [Frankfurter v2](https://frankfurter.dev/)로
정한다. 현재 사용 통화인 `KRW`, `USD`, `JPY`, `CNY`, `EUR`는 Frankfurter의 통화
조회 API로 공급 범위를 확인할 수 있으며, 서비스는 공개 REST API와 중앙은행·공식
데이터 출처 기반 환율 데이터를 제공한다.

| 검토 항목 | 결정 |
| --- | --- |
| 인증·비용 | API 키 없이 사용하며 상업적 이용이 가능하다. |
| 호출 한도 | 월간·일간 quota는 없지만 남용 방지를 위한 rate limit이 있으므로 서버 캐시를 사용한다. |
| 호출 방식 | `GET /v2/rate/{source}/{target}`으로 통화 쌍의 환율과 기준 일자를 조회한다. |
| 데이터 성격 | 실시간 거래·결제 환율이 아닌 참고용 환율이다. |

Frankfurter의 제공 조건과 데이터 출처별 조건은 변경될 수 있으므로 운영 전에는
[공식 문서](https://frankfurter.dev/)와 필요한 공급자 약관을 다시 확인한다.

## 갱신·유효 기간

| 항목 | 현재 기준 |
| --- | --- |
| 캐시 단위 | 원래 통화와 표시 통화의 쌍 |
| 캐시 TTL | 10분 (`MENU_CURRENCY_EXCHANGE_CACHE_TTL`) |
| 연결·읽기 제한 | 각각 2초, 3초 |
| 최대 허용 경과 시간 | 캐시를 저장한 시점부터 10분 |
| 만료 후 동작 | 만료된 값은 사용하지 않고 외부 API를 다시 조회한다. |
| 조회 실패 | 이전 만료 환율로 대체하지 않으며 원래 가격만 반환한다. |

환율 기준 일자는 외부 응답의 `date`를 그대로 보존한다. 캐시 유효 시간은 데이터의
기준 일자와 별개로, 서버가 응답을 재사용할 수 있는 최대 시간이다.

## 장애 기준

- 외부 API 연결·읽기 시간 초과, HTTP 오류, 응답 누락, 숫자가 아닌 환율, 날짜 파싱 오류는 환산 실패로 처리한다.
- 메뉴 목록 API 자체는 실패시키지 않는다. `convertedPrice`를 `null`로 두고 원래 `priceAmount`와 `currency`를 반환한다.
- 환율 데이터는 참고용이므로 결제, 정산, 법정 고지 금액 계산에 사용하지 않는다.

## 구현 대조

`FrankfurterCurrencyExchangeRateClient`와 `application.yaml`의 `menu.currency-exchange`
설정을 대조했다. TTL 내 캐시만 반환하며, 유효하지 않은 응답 또는 `RestClientException`은
빈 결과로 변환한다.
