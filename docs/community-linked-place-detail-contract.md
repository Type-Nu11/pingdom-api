# 커뮤니티 연결 장소 상세 조회 계약

게시글 상세 응답의 `places[].placeId`는 기존 장소 상세 API의 요청 식별자와 동일하다.
별도 커뮤니티 장소 상세 API는 만들지 않고 기존 API를 재사용한다.

## 요청

```http
GET /places/{placeId}
```

예를 들어 게시글 상세 응답의 `placeId`가 `7`이면 클라이언트는 `GET /places/7`을 요청한다.

## 응답 기준

- 정상 장소는 기존 `PlaceDetailResponse`를 그대로 반환한다.
- 없는 장소 또는 삭제된 장소는 기존 `404 PLACE_NOT_FOUND` 응답을 그대로 사용한다.
- 게시글 상세에서 `deleted: true`인 연결 장소는 상세 요청 버튼을 제공하지 않는다.

이 계약은 장소 상세 API의 요청·응답 형식과 기존 장소 조회 동작을 변경하지 않는다.
