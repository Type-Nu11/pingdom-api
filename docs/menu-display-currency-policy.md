# 메뉴 표시 통화 결정 정책

## 적용 범위

관광객용 `GET /places/{placeId}/menus`는 로그인 사용자의 계정 국가 코드로 메뉴의
참고 표시 통화를 정한다. 메뉴 원래 통화와 가격은 어떤 경우에도 변경하지 않는다.

## 지원 통화와 국가 매핑

| 표시 통화 | 국가 코드 |
| --- | --- |
| `KRW` | `KR`, `KOR` |
| `USD` | `US`, `USA` |
| `JPY` | `JP`, `JPN` |
| `CNY` | `CN`, `CHN` |
| `EUR` | `AT`, `BE`, `CY`, `DE`, `ES`, `EE`, `FI`, `FR`, `GR`, `HR`, `IE`, `IT`, `LT`, `LU`, `LV`, `MT`, `NL`, `PT`, `SI`, `SK` |

국가 코드는 대소문자와 앞뒤 공백을 정규화한 뒤 비교한다. 위에 없는 국가 코드는
지원 통화로 추정하지 않고 `KRW`로 처리한다.

## 기본값과 사용자 선택

| 상황 | 표시 통화 |
| --- | --- |
| 비로그인 사용자 | `KRW` |
| 계정 조회 실패 또는 국가 값이 `null`, 빈 값 | `KRW` |
| OAuth 가입 기본값 `UNKNOWN` | `KRW` |
| 미지원 국가 코드 | `KRW` |

사용자가 메뉴 표시 통화를 직접 지정하거나 저장하는 기능은 현재 제공하지 않는다.
프로필의 국가 값은 표시 통화 결정을 위한 입력일 뿐, 통화 선택을 위한 별도 사용자
설정은 아니다. 직접 선택 기능은 API 계약, 사용자 설정 저장, 기존 응답 호환성을 함께
검토하는 별도 이슈에서 다룬다.

## 구현 대조

`MenuDisplayCurrencyResolver`의 `COUNTRY_CURRENCIES`와 `resolve` 메서드를 기준으로
확인했다. `PlaceMenuService#listPublic`은 로그인 사용자의 국가만 전달하며, 비로그인
요청에는 `null`을 전달해 기본값 `KRW`를 적용한다.
