# 신고 및 제재 운영 정책

## 목적

신고 누적/검증 결과가 운영 조치로 이어지도록 신고자 신뢰도, 게시글 자동 숨김, 이의제기와 복구 기준을 정의한다.

## 신고자 신뢰도

신고자는 `reporter_moderation_policy`에 누적 상태를 가진다.

| 항목 | 기준 |
| --- | --- |
| 초기 신뢰도 | 100 |
| 수락된 신고 | 신뢰도 +5 |
| 반려된 신고 | 허위 신고 신호 1회, 신뢰도 -20 |
| 신뢰도 범위 | 0~100 |
| 신고 제한 | 허위 신고 신호 3회 이상 |
| 제한 기간 | 7일 |

제한 기간이 지난 reporter는 다음 신고 시 제한 상태가 해제된다. 기존 abuse rate limit은 요청 빈도 제한이고, reporter 신뢰도 제한은 운영 품질 제한이므로 별도 정책으로 관리한다.

## 자동 숨김

게시글은 삭제하지 않고 `visibility_status`로 노출 상태를 관리한다.

| 상태 | 의미 |
| --- | --- |
| `ACTIVE` | 앱 조회에 노출 |
| `AUTO_HIDDEN` | 신고 정책 또는 관리자 처리로 앱 조회에서 제외 |

자동 숨김은 `PENDING`, `ACCEPTED` 신고의 reporter 신뢰도 가중 점수가 3점 이상일 때 적용한다.

| reporter 신뢰도 | 신고 가중치 |
| --- | --- |
| 80 이상 | 1.0 |
| 50 이상 80 미만 | 0.75 |
| 50 미만 | 0.5 |

관리자 신고 수락은 신고 상태를 `ACCEPTED`로 바꾸고 대상 사용자를 제재하며 게시글을 `AUTO_HIDDEN`으로 전환한다. 실제 삭제는 별도 관리자 삭제 API에서 처리한다.

## 이의제기와 복구

신고 대상 사용자는 `/map/report-appeals`로 이의제기를 제출할 수 있다. 제재 사용자는 일반 API 접근은 차단되지만, 이의제기 제출 경로에서만 활성 계정 여부를 확인해 인증을 허용한다.

| 상태 | 의미 |
| --- | --- |
| `SUBMITTED` | 관리자 검토 대기 |
| `APPROVED` | 이의제기 승인 및 복구 완료 |
| `REJECTED` | 이의제기 반려 |

관리자가 이의제기를 승인하면 게시글을 `ACTIVE`로 복구하고, 대상 사용자가 제재 중이면 제재를 해제한다. 관련 신고는 `RESTORED` 상태로 전환한다.

## 감사 로그

관리자 처리 경로는 감사 로그를 남긴다.

| 액션 | 기록 조건 |
| --- | --- |
| `POST_HIDDEN` | 관리자 신고 수락 또는 관리자 숨김 처리 |
| `POST_RESTORED` | 이의제기 승인으로 게시글 복구 |
| `APPEAL_APPROVED` | 이의제기 승인 |
| `APPEAL_REJECTED` | 이의제기 반려 |
| `USER_BAN_RELEASED` | 이의제기 승인으로 사용자 제재 해제 |
