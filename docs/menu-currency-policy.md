# 메뉴 표시 통화·환율 정책

## 목적과 적용 범위

이 문서는 관광객용 `GET /places/{placeId}/menus`의 메뉴 표시 통화와 참고 환산 가격
정책을 정리한다. 실제 결제 금액은 항상 메뉴의 원래 `priceAmount`와 `currency`를
기준으로 하며, 환산 가격은 비교를 돕는 참고 정보다.

## 확정 정책

| 항목 | 결정 |
| --- | --- |
| 지원 통화 | `KRW`, `USD`, `JPY`, `CNY`, `EUR` |
| 표시 통화 결정 | 로그인 사용자는 계정의 국가 코드로 결정하고, 비로그인·국가 누락·미지원 국가는 `KRW`를 사용한다. |
| 사용자 직접 변경 | 현재 제공하지 않는다. 표시 통화를 수정하는 API·프로필 필드는 이번 범위에서 제외한다. |
| 환율 제공 | Frankfurter v2 공개 API를 사용한다. 서버 설정의 기본 URL은 `https://api.frankfurter.dev/v2`다. |
| 갱신·재사용 | 통화 쌍별 조회 결과는 10분간 메모리에 보관한다. 만료된 값은 재사용하지 않고 다시 조회한다. |
| 장애 처리 | 환율 조회가 실패하거나 결과가 없으면 원래 가격만 반환하고 `convertedPrice`는 `null`이다. |
| 환산 정밀도 | `KRW`, `JPY`는 소수점 0자리, `USD`, `CNY`, `EUR`는 2자리로 `HALF_UP` 반올림한다. |

## 정상·실패 시나리오

| 상황 | 응답 기준 |
| --- | --- |
| 로그인 사용자의 국가가 `US`이고 원래 통화가 `KRW` | `USD` 참고 환산 가격과 환율 기준 일자를 함께 반환한다. |
| 비로그인 사용자 또는 국가 코드가 `UNKNOWN` | 표시 통화는 `KRW`다. 원래 통화도 `KRW`면 환산 가격은 반환하지 않는다. |
| 원래 통화와 표시 통화가 같음 | 외부 환율 API를 호출하지 않고 `convertedPrice`는 `null`이다. |
| 외부 API 시간 초과·오류·잘못된 응답 | 메뉴 목록 조회는 성공하며 원래 가격·통화만 반환한다. |
| 캐시 유효 시간 경과 후 조회 실패 | 만료된 환율은 반환하지 않고 원래 가격·통화만 반환한다. |

세부 국가 매핑은 [표시 통화 정책](menu-display-currency-policy.md), 환율 서비스·
캐시 기준은 [환율 제공 정책](menu-exchange-rate-policy.md), 응답 필드·반올림 기준은
[환산 가격 응답 계약](menu-price-display-contract.md)에서 관리한다.

## 구현 대조

- `MenuDisplayCurrencyResolver`가 국가 코드와 기본 `KRW`를 결정한다.
- `FrankfurterCurrencyExchangeRateClient`가 환율 API 호출과 통화 쌍별 10분 캐시를 담당한다.
- `MenuPriceConversionService`가 `HALF_UP` 반올림과 환산 실패 시 `null` 처리를 담당한다.
- `PlaceMenuPublicResponse`는 원래 가격·통화를 항상 보존하고, 참고 환산 가격만 선택적으로 노출한다.
