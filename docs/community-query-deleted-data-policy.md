# 커뮤니티 조회 및 삭제 데이터 노출 정책

이 문서는 [#1536](https://github.com/Type-Nu11/pingdom-api/issues/1536)에서 확정한 커뮤니티 게시글·댓글 조회, 삭제 데이터 노출, 장소 조회와 장소 언급 지표 기준을 정의한다.

## 적용 범위

- 게시글 목록과 댓글 목록의 기본 정렬·페이지네이션
- 삭제된 게시글과 연결 장소의 조회 응답
- 게시글에서 장소 상세로 진입할 때의 장소 조회수 집계
- 장소 언급 게시글 수의 정의와 외부 노출 범위

기존 API와 데이터 모델을 변경하지 않는다. 이 문서는 이후 커뮤니티 기능 구현 시 적용할 정책만 정의한다.

## 게시글과 댓글 조회 기준

| 대상 | 표시 위치 | 기본 정렬 | 최초 조회 개수 | 추가 조회 |
|---|---|---|---:|---|
| 게시글 목록 | 카테고리별 게시글 목록 | 최신 등록순 | 20개 | 다음 페이지 조회 |
| 댓글 목록 | 게시글 상세 본문 아래 | 최신 댓글순 | 20개 | 더 보기 요청 |

- 게시글 목록의 최신 등록순은 `createdAt DESC`를 기본으로 한다.
- 같은 작성 시각의 게시글은 식별자를 보조 정렬 기준으로 사용해 목록 순서를 안정적으로 유지한다.
- 댓글은 별도 목록 화면이 아니라 게시글 상세 응답에서 본문 아래에 표시한다.
- 다음 페이지 또는 더 보기 요청의 구체적인 요청 파라미터는 기존 프로젝트의 페이지네이션 형식을 유지한다.

## 삭제 데이터 노출 기준

| 대상 | 목록 조회 | 상세 조회 | 응답 기준 |
|---|---|---|---|
| 삭제된 게시글 | 노출하지 않음 | 조회 불가 | 존재하지 않는 게시글과 동일한 기존 실패 응답을 사용한다. |
| 삭제된 연결 장소 | 해당 없음 | 게시글 상세에서 연결 항목을 유지 | `삭제된 장소입니다`로 표시한다. |

- 삭제된 게시글은 카테고리 목록과 게시글 상세 모두에서 제외한다.
- 삭제된 장소 때문에 게시글 자체를 숨기거나 조회 불가 처리하지 않는다.
- 삭제 장소의 ID 연결은 유지해 데이터 관계를 보존하고, 장소 이름·상세 정보는 제공하지 않는다.

## 장소 조회수와 장소 언급 게시글 수

두 지표는 목적과 집계 시점이 다르다.

| 지표 | 의미 | 집계 기준 | 외부 노출 |
|---|---|---|---|
| 장소 조회수 | 게시글에서 연결 장소 상세로 진입한 횟수 | 사용자·장소 기준 하루 1회 | 기존 기능 범위에서만 제공한다. |
| 장소 언급 게시글 수 | 특정 장소 ID가 연결된 게시글 수 | 게시글-장소 연결 관계 기준 | DB 내부 지표로만 유지하며 API 응답에 추가하지 않는다. |

- 장소 조회수는 게시글 상세의 연결 장소를 눌러 장소 상세로 진입한 경우에만 증가한다.
- 같은 사용자가 같은 장소를 반복 조회해도 하루에 한 번만 집계한다.
- 장소 화면의 직접 조회 등 기존 조회 경로와 응답은 이 정책으로 변경하지 않는다.
- 장소 언급 게시글 수는 조회·분석을 위한 내부 데이터이며, 기존 장소 상세 응답이나 다른 API에 필드를 추가하지 않는다.

## 구현 시 준수 사항

- 기존 Controller, Service, Repository, DTO, ErrorCode, 공통 응답 형식을 변경하지 않는다.
- 기존 기능에 새 API 응답 필드나 화면 노출을 추가하지 않는다.
- 이후 #1545, #1547, #1550, #1551, #1555, #1559 구현 시 이 문서를 조회 기준으로 사용한다.
